## Deliberate omissions — the claims discipline for this product

- **No blank count is stated.** See the note below; the number is ambiguous and not worth publishing.
- **Nothing says the letter "removes", "deletes", "clears", or "fixes" anything.** A validation letter asks for verification; the copy says exactly that.
- **Nothing says collectors must stop contacting the buyer.** Section 7 is described for what it is — a request written into the letter — not as an entitlement.
- **Nothing implies a credit-report outcome** of any kind, including that a dispute must be removed from a report if unverified.
- **No claim about how a collector must respond, or by when.** The response period is described as "a blank where you enter a number of days", which is what the file actually contains.
- **Nothing about debts being forgiven, settled, or written off.**
- **No reviews, ratings, buyer counts, or results** — there are no customers yet, so any such line would be invented.
- **No urgency, no comparison to other sellers, no state-specific suitability claim.**

## Why the "22 blanks" figure is not in the copy

The approved source actually contains **24** bracketed spans. The figure of 22 comes from counting with a simple regex, which undercounts because two blanks contain a nested bracket (for example the record line: `[OPTIONAL … "Sent by [METHOD] on [DATE]."]`). On top of that, several of those brackets are delete-this-note instructions rather than fields the buyer fills in.

So "22 blanks" is neither the span count nor a clean field count. Rather than print a number that could be challenged, the copy uses the same line the other kits use — every blank is shown in bold inside a shaded block — and states no count. If the owner wants a number on the listing, it should be counted against a specific definition (fillable fields only) first.
